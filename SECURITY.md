# Security policy

Do not open a public issue containing a real Stocky API key, merchant archive, supplier details,
purchase data, or other sensitive store information.

Report a suspected credential leak, unexpected network destination, archive-integrity flaw, or
other security issue privately to `support@shelftally.com`. Include reproduction steps using
synthetic fixtures only. Do not attach a merchant archive.

The supported release is the latest version listed in GitHub Releases. Rotate a Stocky key
immediately if you believe it was exposed, and do not wait for a software fix before protecting
the merchant account.
