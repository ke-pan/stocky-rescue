# Stocky Rescue moved

Stocky Rescue `v0.2.0` makes the product repository itself the Agent Skill package. The separate
Skill copy and its Python inspector were removed so export and inspection use one bundled Node.js
CLI.

Open the [repository root](../..) for installation instructions, or use the verified
[`v0.2.0` release](https://github.com/ke-pan/stocky-rescue/releases/tag/v0.2.0), which contains both
`SKILL.md` and `dist/stocky-rescue.mjs`.
